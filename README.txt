GLOW & GRACE — COMPLETE FRONT-END WEBSITE DEMO

1. Extract this ZIP file.
2. Open the glow_grace_complete_website folder.
3. Double-click index.html to open it in Chrome or Edge.
4. Photos are stored in the images folder, so they load locally without internet.
5. Google Fonts may use internet; the site still works if fonts cannot load.

BEFORE CLIENT DELIVERY
- Change the demo brand name in index.html.
- Replace sample address, phone, email, hours, and business story with the client's real details.
- Replace sample/cropped inspiration images in images/ with clear photos the parlour owns or has permission to use.
- In script.js replace PARLOUR_WHATSAPP with the client's real WhatsApp number including country code, digits only.
- The booking form opens WhatsApp; it does not save bookings to a database or confirm appointments automatically.
- Add the client's actual service prices; no prices are invented in this demo.
- Upload the folder to a hosting service to get a public live link. Opening index.html locally is not a public link.

This is a responsive HTML/CSS/JavaScript front-end website, not a backend/admin system.
